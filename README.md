# 🚀 Galaxy War

**Galaxy War** is a simple arcade-style space shooter created with **Unity** as part of a learning process.

The goal of the game is straightforward:
**destroy enemy ships while avoiding obstacles and collisions.**

🎮 **Play the game here:**  
👉 https://play.unity.com/en/games/209f0650-7798-431b-babf-da50bbd38764/docs

---

## 🕹️ Gameplay

- Control a spaceship moving through space
- Shoot incoming enemy ships
- Avoid obstacles and enemy collisions
- Focus on survival and basic combat mechanics

This project was built mainly for **practice and learning**, based on a Unity course.

---

## ✨ Features

- Basic enemy spawning and shooting mechanics
- Obstacle avoidance
- Simple particle effects
- WebGL build playable in the browser

---

## 🎯 Objective

- Destroy enemies  
- Avoid obstacles  
- Survive as long as possible  

---

## 🛠️ Built With

- Unity
- C#
- WebGL
